# 设置页：说明收进 `ⓘ`，值放标签旁

来源：WSight v0.4.3 的设置面板（做法见其会话里的《设置项提示收纳方案》），2026-09-15 移植到 AIQuad。
这份文档记的是**移植时定下来的规矩和踩到的坑**，改 `settings.html` / `styles.css` 的设置页段落之前先读一遍。

---

## 一、要解决的问题

设置窗口的典型毛病是"越写越长"：每个开关下面跟一句解释，一行变两行，两行变三行。
用户要滚三屏才找到那个开关 —— 而设置页**一辈子只被认真读一次**，就是找控件的那次。

所以：**行内只放「名字 + 当前值 + 控件」。任何需要一整句话才能说清的内容，收进标签旁边一个
13px 的 `ⓘ` 圆点里，悬浮才显示。**

## 二、三条不能破的规则

1. **一行一件事。** 行底下不留说明句。要解释就进 `ⓘ`。
2. **值和提示分工。** 值是"现在是多少"（`30% · 约 596 px`），放标签右边、弱色、等宽数字；
   提示是"这是什么 / 为什么这么设计"，进 `ⓘ`。**值塞进 tooltip 等于把它藏起来。**
3. **别每行都挂 `ⓘ`。** 只在"用户会问为什么 / 这是什么"的行加。一屏十几个小圆圈就是新的噪音，
   比原来那几句说明还吵。

## 三、视觉规格

| 项 | 规格 | 实现在哪 |
| --- | --- | --- |
| `ⓘ` 形状 | 13×13px 正圆，1px 实边，`border-radius: 50%` | `.st-info` |
| `ⓘ` 内容 | 字母 `i`，9px / 字重 700 / `font-style: normal`（载体是 `<i>`，不去斜体就歪） | `.st-info` |
| `ⓘ` 静止 → 悬浮 | 边框与文字同时变强调色，`transition: color .12s, border-color .12s` | `.st-info:hover` |
| `ⓘ` 光标 | `cursor: help` —— 悬浮就是全部交互，没有东西可以点 | `.st-info` |
| `ⓘ` 位置 | 紧跟标签文字之后，间距 6px；`flex: 0 0 auto` 防止被压扁 | `.st-row-label` |
| 行本身 | flex 两端对齐，`gap: 12px`，`padding: 7px 0` | `.st-row` |
| 行分隔 | 只用 `border-top`，**首行不留线**；两侧夹了状态行的那两行单独补 | 文件末尾那组选择器 |
| 当前值 | 标签右侧，11.5px、弱色、`font-variant-numeric: tabular-nums`（拖滑块时不抖） | `.st-row-value` |

## 四、AIQuad 上的具体落法

- **卡片走两列网格**（`.st-grid`）。设置窗口宽 920px，一行行铺满的话控件会离它自己的标签好几百像素远。
  需要整宽的加 `.wide`：面板与呼出、AI 服务、数据与缓存、关于。
  同排两张卡用 `align-items: start` 各按自己的高度收边，不拉平。
- **属于整组的说明**（例如"隐藏只是从选择器里摘掉，已经开着的格子不受影响"）放**卡片标题右侧**那行
  10.5px 小字（`.st-card-head > span`），与标题 `baseline` 对齐，不占正文的行。
- **控件的说明挂在控件上**：例如"代理策略"这一列的解释（单独代理只在关掉登录态共享后生效）
  直接写成 `<th title="…">`，连 `ⓘ` 都省了。
- **状态/结果行**（快捷键校验结果、代理测试结果、清理结果）夹在行之间，用 `.st-statusline`；
  没内容时用 `:has(> span:empty)` 整条收掉，不留一条空带。
- **AI 服务列表限高 300px**、表头 `position: sticky`。条目数没有上限，不封的话整页高度会随条目数漂。
- **窄窗口**（<820px）退回单列并收窄表格的定宽列 —— 窗口是可缩放的，`table-layout: fixed` 下
  网址列会被挤到 0。

## 五、关键取舍（含已知短板）

- **提示用的是浏览器原生 `title`，不是自绘浮层。** 换来零 JS、零定位计算、不遮控件、不会被窗口边缘
  裁切；代价是**显示延迟由系统决定（约 0.5~1s）、样式跟不了深色主题**（深色应用里系统 tooltip 可能是
  浅色的）、**触屏点不出来**。设置页属于"低频查阅"，这个买卖划算。要即时显示就得换 CSS `::after`
  或 JS 定位浮层，成本立刻上来 —— 先按原生做，不够再升级。
- **无障碍是当前实现的短板，但已补了一半。** `<i title>` 不可聚焦，键盘用户和读屏软件拿不到提示，
  所以每个 `ⓘ` 都写了 `tabindex="0"`（HTML 里逐个写死的，改的时候别漏）。
  补得更彻底要改成 `<button type="button" aria-label="…">` 或 `aria-describedby` + 隐藏文本。
- **`<select>` 必须有不透明背景色。** Chromium 画下拉弹层用的是元素自己的 `background-color`；
  一旦那个颜色带 alpha，它会放弃并改用**系统**菜单色 —— 浅色 Windows 上就是白底，而选项文字是浅色的，
  于是下拉看起来是空的。AI 服务表里的输入框平时透明（悬停才浮出边框），`<select>` 是个例外，
  它始终带着 `--st-field`。
- **吸顶表头别用 `border-bottom`。** `border-collapse: collapse` 下那条边框归表格画，滚起来会丢；
  用 `box-shadow: inset 0 -1px 0 var(--line)` 代替，底色还必须是不透明的，否则下面滚过去的行会透出来。
- **`.st-row` 留了 `flex-wrap: wrap`。** 控件挤不下时整块掉到下一行，而不是被卡片（`overflow: hidden`）
  从右边裁掉一截 —— 被裁掉的那部分是完全看不见的，用户只会觉得"这个开关不见了"。
- **开关仍然是真的 `<input type="checkbox">`**，只是 `appearance: none` 自己画。
  换成一个假 div 就得改 JS，而 `collect() → save()` 那条链路是拿事故换来的（见下），能不动就不动。
- **单选项必须留在文档里。** 停靠位置改成了分段按钮，但 `input[name="position"]` 仍然在 DOM 里
  （藏起来、由 `:checked + span` 负责那层皮），因为回归脚本靠 `input[name="position"]:checked` 判"有选中项"。

## 六、回归契约（改 HTML 前先看这几条）

被脚本钉死的东西，**改名 = 静默坏掉**：

- `settings.js` 里 `$('id')` 引用的每个 id 都必须在 HTML 里存在。
  ⚠️ 缺一个会让 `collect()` 抛异常 —— 结果是**保存时任何一项都不生效，界面还一声不响**。
  真实事故：`opt-shared` 缺失导致"面板宽度比例"改了没反应。
- `.sc-input` 必须正好 4 个：`sc-toggle` / `sc-1` / `sc-2` / `sc-4`，且都是 `readonly`。
- `#ratio-presets button[data-ratio]`、`#ratio-val`（文本必须正好是 `40%` 这种）、`#ratio-px`（`约 N px`）。
- `#ai-rows tr td.ops button`（第一个是隐藏开关）、隐藏行 `tr.className === 'ai-hidden'`、
  隐藏按钮的文案在 `隐藏` / `显示` 之间翻。
- `#save-result` 的文案（`已保存并应用` / `已自动保存`）。
- 缓存统计里 `#cache-stat` 必须含"可清理缓存"、`#cache-detail` 非空。

对应的脚本：`scripts/verify-settings.js`、`scripts/verify-settings-extra.js`、
`scripts/verify-shortcut-capture.js`。

## 七、怎么在不打扰用户的情况下跑这些脚本

官方那三个脚本自己 spawn Electron，**没法传 `--user-data-dir`**；而用户桌面上常常正开着装好的
AIQuad，它握着单实例锁，于是开发实例一启动就静默退出，脚本报的是"面板窗口没起来 / 设置窗口没起来"，
看着像功能坏了。

- Electron 的单实例锁按 **userData 路径**取，**不是**按 `%APPDATA%` 环境变量取 —— 改 `APPDATA` 没用，
  必须走 `--user-data-dir=<隔离目录>`（实测可行）。
- 隔离目录里放一份 config.json（可以从 `%APPDATA%\aiquad\config.json` 复制），
  把 `panes` 置空（否则会在用户桌面上弹出浏览器窗口）、`cacheCleanup` 设成 `off`
  （否则可能在启动时清掉真实档案目录里的缓存）。
- 起跑前把 `hidden` 标记和 `shortcuts` 清掉：真实配置里本来就可能藏着几条隐藏项、而用户的开机快捷键
  正被那个跑着的实例占着，留着会污染判据（"只隐藏了这一个"必然失败、"已保存并应用"会变成
  "已保存，但有快捷键没生效"）。
- 长连 CDP 在保存几次之后会偶发断开（报 `CDP not connected`，Windows 事件日志里没有崩溃记录，
  `verify-settings-extra.js` 的文件头也记着同一件事）—— 断了重连一次再发，别当成功能坏了。
